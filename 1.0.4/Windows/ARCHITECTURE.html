Netory 1.0.4 — Windows architecture

Netory is a self-hosted web application. Users open it in a browser; one application service provides both the web interface and API, with a local SQLite database. A separate database server is not required.

The proxy is optional. A direct connection goes from the browser to Uvicorn; a proxy connection goes through the proxy before reaching Uvicorn.

Main components

  • Browser interface: displays inventory and settings and sends API requests to the server.
  • Uvicorn + FastAPI: handles web requests, authentication and application features using the bundled private Python runtime.
  • SQLite: stores accounts, inventory and application records in a local database file. Database migrations run during setup/update.
  • Service manager: starts Netory automatically at boot and restarts it after an unexpected failure. The application runs as the restricted Windows LocalService account.
  • Licensing: preserves the installation identity locally and contacts https://lic.netory.app. A valid license and online licensing access are required for write access.
  • Network discovery: the server probes managed devices; results depend on network reachability and firewall rules. TCP/ICMP discovery requires Nmap installed separately and available on the machine PATH; restart Netory after installation.

Ports and HTTPS

The default address is http://127.0.0.1:8000/; access is local to the server. Enable private-network access in setup to bind to IPv4 network interfaces and allow local-subnet clients through the Windows firewall on Private profiles. Setup can enable HTTPS directly using your PFX/P12 certificate. Nginx and IIS are optional and are not required.

Files and backups

  • Program and private runtime: C:\Program Files\Netory by default.
  • Data: C:\ProgramData\Netory by default, including db\netory.db, .env, licensing\, logs\ and update backups\.
  • Setup remembers custom application and data locations. HTTPS certificate/key files are stored in the protected data tls folder.

Back up the database together with .env and the licensing directory. Encryption keys are needed to read stored encrypted credentials. Program files are separate from customer data; protected application/runtime files are verified at startup and should not be edited.

Quick service check

Get-Service Netory
Test-NetConnection 127.0.0.1 -Port 8000

Use your configured port if it differs from 8000. The connection check verifies that the TCP port is reachable; open the configured HTTP/HTTPS address in a browser to check the application. Service logs are in the selected data folder.
